Privacy policy: ytmanager uploader

Last updated: 9 November 2026.

Who uses this app

ytmanager uploader is a private tool. Only its owner signs in to it, to manage the owner's own YouTube channels. It is not offered to anyone else.

What it accesses

When the owner signs in with Google, the app asks for two YouTube permissions:

  • youtube.upload, to upload videos to the signed-in channel;
  • youtube.force-ssl, to read the signed-in channel's id and name, and to set video thumbnails, captions, playlists, video status and channel branding.

It does not read anyone else's data, and it does not access Gmail, Drive, contacts or any other Google service.

How data is stored

The sign-in token is stored only on the owner's own computer, in a file readable only by the owner. Video files and their details are stored on the same computer. Nothing is stored on any server run by this app, because there is none.

Sharing

Data is sent only to Google, through the YouTube Data API, to carry out the uploads and changes the owner asks for. It is never sold, shared with third parties or used for advertising.

YouTube and Google terms

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Removing access

Access can be withdrawn at any time at Google Account > Third-party connections or through the Google security settings page. Deleting the token file on the owner's computer also removes the app's stored access.
